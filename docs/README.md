# Arc Pay Agent Docs

This folder is the GitBook-friendly documentation surface for Arc Pay Agent.

It reorganizes the repository docs into:

- `get-started`: onboarding and first-run setup
- `concepts`: runtime model and product concepts
- `build`: practical workflows and regression operations
- `architecture`: system structure and state ownership
- `reference`: commands, scenarios, env vars, and capability tables
